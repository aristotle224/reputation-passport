🛂 Reputation Passport — Embeddable Badge Demo

This page demonstrates the <reputation-badge> custom element dropped into a plain static HTML page — no Angular, React, or framework required.

Set backend-url to your local backend (or testnet API) and address to a Stellar worker address to see live data.

Standard badge

<reputation-badge
  address="GABC…"
  backend-url="http://localhost:3000"
></reputation-badge>

Compact badge

<reputation-badge
  address="GABC…"
  backend-url="http://localhost:3000"
  compact
></reputation-badge>
